# 状态机架构

> 学习来源：cat-knight 项目玩家角色重构

## 概述

状态机是一种将对象行为分解为离散状态的设计模式。在游戏开发中，状态机特别适合处理角色的各种行为状态（待机、移动、攻击、受伤等）。

## 核心组件

### StateMachine（状态机）

负责管理所有状态和状态切换：

```gdscript
class_name StateMachine
extends Node

var states: Dictionary = {}
var current_state: State = null
@export var initial_state: State

func _ready() -> void:
    # 自动注册所有子节点状态
    for child in get_children():
        if child is State:
            states[child.name] = child
            child.transitioned.connect(_on_transitioned)

    if initial_state:
        initial_state.enter()
        current_state = initial_state

func _physics_process(_delta: float) -> void:
    if current_state:
        current_state.update(_delta)

func _on_transitioned(state_name: String) -> void:
    var new_state = states.get(state_name)
    if not new_state:
        return

    if current_state:
        current_state.exit()

    print("状态切换：%s -> %s" % [current_state, new_state])
    new_state.enter()
    current_state = new_state
```

### State（状态基类）

所有具体状态的父类，定义状态的生命周期：

```gdscript
class_name State
extends Node

signal transitioned(state_name: String)
var state_machine: StateMachine = null

func enter() -> void:
    pass  # 进入状态时调用

func exit() -> void:
    pass  # 离开状态时调用

func update(_delta: float) -> void:
    pass  # 每帧调用
```

## 具体状态实现

### IdleState（待机状态）

```gdscript
extends State

@onready var player = get_owner()

func enter() -> void:
    pass

func update(_delta: float) -> void:
    var direction = player.get_input_direction()
    if direction != Vector2.ZERO:
        transitioned.emit("MoveState")
```

### MoveState（移动状态）

```gdscript
extends State

@onready var player = get_owner()

func update(delta: float) -> void:
    var direction = player.get_input_direction()

    # 冲刺检测
    if Input.is_action_just_pressed("dash"):
        transitioned.emit("DashState")
        return

    # 停止检测
    if direction == Vector2.ZERO:
        transitioned.emit("IdleState")
        return

    # 移动
    player.movement_component.accelerate_in_direction(direction, delta)
    player.movement_component.move(player)
```

### DashState（冲刺状态）

```gdscript
class_name DashState
extends State

@export var dash_speed: float = 800.0
@export var dash_duration: float = 0.2

@onready var player = get_owner()

var _timer: float = 0.0
var _dash_direction: Vector2 = Vector2.ZERO

func enter() -> void:
    var direction = player.get_input_direction()
    if direction == Vector2.ZERO:
        direction = Vector2.RIGHT

    _dash_direction = direction
    _timer = dash_duration
    player.movement_component.velocity = _dash_direction * dash_speed

func update(_delta: float) -> void:
    _timer -= _delta

    if _timer <= 0:
        transitioned.emit("IdleState")
        return

    player.movement_component.velocity = _dash_direction * dash_speed
    player.movement_component.move(player)

func exit() -> void:
    player.movement_component.velocity = Vector2.ZERO
    player.velocity = Vector2.ZERO
```

## 状态切换机制

1. **信号驱动**：状态通过 `transitioned.emit("StateName")` 发出切换信号
2. **状态机响应**：状态机监听到信号后，执行 `exit()` -> `enter()` 流程
3. **状态隔离**：每个状态只关心自己的逻辑，切换时自动清理

## 架构优势

| 优势 | 说明 |
|------|------|
| **职责分离** | 每个状态独立管理自己的行为 |
| **易于扩展** | 新增状态只需继承 State 类 |
| **状态清晰** | 避免大量 if/else 条件判断 |
| **易于维护** | 修改一个状态不影响其他状态 |

## 适用场景

- 角色行为控制（待机、移动、攻击、受击等）
- AI 状态机（巡逻、追击、逃跑等）
- 游戏流程控制（菜单、游戏、暂停、结算等）
