# Enter The Dungeon Demo - 地牢探索游戏

> Godot 4.6 地牢探索动作游戏 Demo，学习多角色系统、武器系统和国际化支持

## 项目概述

| 属性 | 值 |
|------|-----|
| **引擎** | Godot 4.6 |
| **渲染** | Forward Plus |
| **物理** | Jolt Physics |
| **分辨率** | 640x360 (可拉伸到 1920x1080) |
| **特性** | 多角色选择、武器系统、本地化(中/英) |

## 项目结构

```
enter-the-dungeon-demo/
├── Autoloads/          # 自动加载(全局脚本)
│   ├── event_bus.gd   # 事件总线
│   ├── global.gd      # 全局数据/存档
│   ├── music.tscn     # 音乐管理
│   └── transition.gd # 场景过渡
├── Data/               # 数据资源

│   ├── Arena/          # 战斗 arena
│   ├── CharacterSelection/ # 角色选择

│   ├── localization.en.translation

```

## 核心系统

### 1. 多角色选择系统

**角色数据 (Resource):**
- `player_bunny.tres` - 兔子
- `player_cat.tres` - 猫
- `player_dog.tres` - 狗
- `player_mouse.tres` - 老鼠

每个角色有独立属性：
- `max_hp` - 最大生命值
- `move_speed` - 移动速度
- `sprite_frames` - 精灵帧动画

### 2. 玩家控制器

```gdscript
# player.gd - 玩家核心逻辑
extends CharacterBody2D
class_name Player

@export var data: PlayerData  # 角色数据 resource

@onready var health_component: HealthComponent

func _physics_process(delta):
    direction = Input.get_vector("move_left", "move_right", "move_up", "move_down")
    movement = direction * data.move_speed
    move_and_slide()
```

**特点：**
- 使用 `CharacterBody2D` 处理物理
- 通过 `@export` 引用角色数据资源
- 8方向移动 (WASD)
- 生命值组件化 (`HealthComponent`)

### 3. 事件总线模式

```gdscript
# event_bus.gd - 全局事件
extends Node

# 玩家生命值变化信号
signal on_player_health_updated(current: float, max: float)
```

**使用:**
```gdscript
# 发送事件
EventBus.on_player_health_updated.emit(health, max_hp)

# 接收事件
func _ready():
    EventBus.on_player_health_updated.connect(_on_health_updated)
```

### 4. 本地化系统

支持中英文，通过 `tr()` 函数翻译：

```gdscript
# project.godot 配置
[internationalization]
locale/translations=PackedStringArray(
    "res://Localization/localization.en.translation",
    "res://Localization/localization.zh_CN.translation"
)
```

```gdscript
# 使用翻译
var text = tr("KEY_NAME")
```

### 5. 存档系统

```gdscript
# global.gd - 用户设置存档
var save_path := "user://save.json"

func save_data():
    var file = FileAccess.open(save_path, FileAccess.WRITE)
    file.store_string(JSON.stringify(settings))

func load_data():
    var file = FileAccess.open(save_path, FileAccess.READ)
    var data = JSON.parse_string(file.get_as_text())
```

## 技术亮点

### ✅ 自动加载 (Autoload)
4个全局单例:
- `Transition` - 场景切换过渡
- `Global` - 全局数据/存档
- `Music` - 背景音乐
- `EventBus` - 事件总线

### ✅ 资源驱动开发
- 角色属性存储在 `.tres` 文件
- 武器数据独立管理
- 方便策划调整数值

### ✅ 物理引擎
- 使用 Jolt Physics (高性能物理)
- 适合 2D 动作游戏

### ✅ 响应式 UI
- 基础分辨率 640x360
- 拉伸到 1920x1080
- `window/stretch/mode = "canvas_items"`

## 学习要点

1. **Resource 机制**: 如何创建可配置的数值资源
2. **Autoload**: 全局脚本的使用场景
3. **事件总线**: 解耦模块间通信
4. **本地化**: 国际化支持实现
5. **Jolt Physics**: 高性能物理集成
