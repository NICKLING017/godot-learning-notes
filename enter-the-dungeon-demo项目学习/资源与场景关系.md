# 资源与场景关系

> Godot 中资源 (.tres) 与场景 (.tscn) 的关系，以及实际开发中的使用技巧

## preload vs load

```gdscript
# preload - 编译时加载，返回 PackedScene 对象（常量）
const PLAYER_SCENE = preload("res://path/to/player.tscn")

# load - 运行时加载，返回 Resource（可变）
var scene = load("res://path/to/player.tscn")
```

**区别：**
- `preload` 在编译时执行，脚本加载时即完成
- `load` 在运行时执行，调用时才加载
- `preload` 适合固定资源，`load` 适合动态资源

## 场景切换

```gdscript
# 方式1: 字符串路径（推荐，最可靠）
Transition.transition_to("res://Scenes/Arena/arena.tscn")

# 方式2: PackedScene 对象（需要确保函数参数类型匹配）
func transition_to(scene: PackedScene):
    get_tree().change_scene_to_packed(scene)
```

**注意：** 不要使用 `.resource_path`，在某些情况下会返回空字符串。

## 资源和场景的关系

```
.tres 文件 (Resource)  - 数据容器，如 PlayerData, WeaponData
.tscn 文件 (PackedScene) - 场景/节点树结构
```

**给场景赋值 data：**

```gdscript
# 方式1: 在场景的 _ready() 中读取 data
func _ready():
    if data and data.weapon_icon:
        sprite.texture = data.weapon_icon

# 方式2: 使用 setter
func set_data(value: WeaponData):
    data = value
    if data:
        sprite.texture = data.weapon_icon
```

## Autoload 初始化时序问题

**问题：** Autoload 的 `@export` 变量可能在其他场景的 `_ready()` 调用时还没初始化完成。

```gdscript
# global.gd
@export var all_players: Dictionary[String, PackedScene] = {}

func get_player() -> PackedScene:
    if all_players.is_empty() or selected_player == null:
        return null
    return all_players.get(selected_player.id)
```

**调用方需要做空值检查：**

```gdscript
# arena.gd
func load_game_selection():
    var player_scene = Global.get_player()
    if player_scene == null:
        return
    var player = player_scene.instantiate()
    add_child(player)
```

## Dictionary 使用技巧

```gdscript
# 定义带类型的 Dictionary
var all_players: Dictionary[String, PackedScene] = {
    "Bunny": preload("uid://..."),
    "Cat": preload("uid://...")
}

# 使用 .get() 代替 [] 访问，更安全
return all_players.get(selected_player.id)  # 不存在返回 null
# return all_players[selected_player.id]    # 不存在会报错
```

## 实战：角色选择系统

1. **Data 资源** - `.tres` 文件存储角色/武器属性
2. **场景实例化** - 用 Dictionary 存储 PackedScene
3. **选择传递** - 点击卡片时设置 `Global.selected_player`

```gdscript
# global.gd
var all_players: Dictionary[String, PackedScene] = {
    "Bunny": preload("uid://..."),
    "Cat": preload("uid://...")
}
var selected_player: PlayerData

# character_selection.gd
func _on_player_card_pressed(player: PlayerData):
    Global.selected_player = player
```
