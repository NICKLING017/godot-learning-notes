# Enter The Dungeon Demo - 多语言系统

> 项目路径: `C:\Godot\enter-the-dungeon-demo`

## 概述

本项目使用 Godot 4 的内置国际化(i18n)系统实现多语言支持，支持中文(zh-CN)和英文(en)。

---

## 1. 配置 (project.godot)

```ini
[internationalization]
locale/translations=PackedStringArray("res://Localization/localization.en.translation", "res://Localization/localization.zh_CN.translation")
locale/test="en"
locale/locale_filter_mode=0
```

**参数说明:**
- `locale/translations`: 翻译文件路径数组
- `locale/test`: 测试用语言
- `locale/locale_filter_mode`: 语言过滤模式 (0=所有语言)


## 3. 代码中使用翻译

### 基本用法: `tr()`

```gdscript
label.text = tr("WEAPON_PISTOL_NAME")
# 输出: "手枪" 或 "Pistol" (根据当前语言)
```

### 格式化字符串

```gdscript
label.text = "%s: %s" % [tr(bus_name.to_upper()), tr("ON") if is_on else tr("OFF")]
# 输出: "MUSIC: 开" 或 "MUSIC: ON"
```

### 完整示例 (main_menu.gd)

```gdscript
extends Control
class_name MainMenu

@onready var music_label: Label = %MusicLabel

func update_audio_bus(bus_name: String, label: Label, is_on: bool) -> void:
    AudioServer.set_bus_mute(AudioServer.get_bus_index(bus_name), not is_on)
    label.text = "%s: %s" % [tr(bus_name.to_upper()), tr("ON") if is_on else tr("OFF")]

func update_fullscreen(is_on: bool) -> void:
    var mode = DisplayServer.WINDOW_MODE_FULLSCREEN if is_on else DisplayServer.WINDOW_MODE_WINDOWED
    DisplayServer.window_set_mode(mode)
    window_label.text = tr("FULLSCREEN") if is_on else tr("WINDOWED")
```

## 4. 切换语言

使用 `TranslationServer.set_locale()`:

```gdscript
func _on_zh_cn_button_toggled(toggled_on: bool) -> void:
    if toggled_on:
        TranslationServer.set_locale("zh_CN")
        update_ui_text()

func _on_en_button_toggled(toggled_on: bool) -> void:
    if toggled_on:
        TranslationServer.set_locale("en")
        update_ui_text()
```

**注意:** 切换语言后需要手动刷新UI文本 (`update_ui_text()`)

## 7. 最佳实践

1. **统一key命名**: 使用大写下划线 (如 `WEAPON_PISTOL_NAME`)
2. **分类前缀**: 
   - `WEAPON_` 武器相关
   - `PROPERTY_` 属性相关
   - `UI_` 或 `SETTINGS_` 界面相关
3. **保持CSV同步**: 修改 `.xlsx` 后导出 CSV
4. **刷新UI**: 语言切换后调用 `update_ui_text()` 刷新所有文本
